# Data Analytics & AI Foundations

### BrightLearn Research Assignment

## Overview

This repository contains my **Research Assignment 1** for the *BrightLearn Data Analytics & Data Science* course. It covers fundamental concepts in **data analytics, artificial intelligence, machine learning, APIs, and data governance**.

The assignment demonstrates my understanding of core data concepts and their real-world applications.

## Objectives

Understand key **data fundamentals** such as databases and data storage
Explore **AI and Machine Learning concepts**
Learn about **APIs and developer tools**
Understand **data ethics, governance, and privacy**
Apply theoretical knowledge through research-based answers


## Topics Covered

### Section A: Data Fundamentals

* Databases, Data Warehouses, Data Lakes, Data Marts
* Data types (Structured, Semi-Structured, Unstructured)
* Data Modeling & Data Mining
* DBMS and ETL processes
* Data storage formats (CSV, JSON, Parquet, Avro)

### Section B: Artificial Intelligence & Machine Learning

* Artificial Intelligence (AI)
* Machine Learning (ML) types
* Deep Learning and Neural Networks
* Natural Language Processing (NLP)
* Large Language Models (LLMs)
* Generative AI and Computer Vision

### Section C: APIs & Developer Concepts

* APIs and REST APIs
* API Keys and Security
* JSON and Data Exchange
* Prompt Engineering
* Cloud Computing (IaaS, PaaS, SaaS)
* Version Control (Git)
* Jupyter Notebooks and Python

### Section D: Data Ethics, Governance & Careers

* Data Privacy and GDPR
* Data Ethics and AI Bias
* Data Governance
* Data-related career roles
* Business Intelligence (BI) tools
  
### Section E: Personal Reflection

* Learning experiences
* Challenges faced
* Future impact of Data & AI

## Tools & Technologies

* Git & GitHub
* Power BI (theoretical)
